# 0.3 部署边界：可信局域网，免身份认证

当前默认后端是 Gin + MySQL，配置在 `backend/config.local.yaml`，启动 `bash start-server.sh`；后台在 `/admin/`。需要先运行 `bash setup-backend.sh` 初始化并构建 Vue。

为便于 iPhone 连接，默认监听 `0.0.0.0:8787`，不是仅监听回环。任何能到达端口的用户/程序均可读取、上传、删除全部健康摘要。只在你信任的网络内开放；不要把办公室共享网络当成自动安全，也不要做公网映射、公开隧道或公开反向代理。

此版按单人使用需求移除了 Token，不提供账号、登录、用户隔离或身份审计。HTTPS 并不能把免认证服务变成私有服务。确需远程访问前，应先实现并验证账号密码认证、会话与访问控制，而不是直接公开 8787。

保留浏览器 origin 检查、严格 JSON 验证、128 KiB 限制、超时、禁止重定向、演示上传隔离及 no-store 响应。上述措施都不是身份认证，也不能阻止局域网内其它客户端调用 API。

MySQL 使用专用受限账号，不要在正式环境使用 root/弱密码；保护配置文件与磁盘、定期加密备份。配置的 0600 权限不意味着内容已经加密。不要提交真实数据库或健康截图到公开仓库。

删除 `DELETE /v1/snapshot` 会删除 MySQL 全部历史和最新指针，不删除 Apple 健康原始记录、旧 SQLite 或独立备份。停止使用时先关闭服务，再按需要处理自己的数据库与备份。

`server/` 中的 Python 服务是历史版本参考，非当前默认实现，其 Token/SQLite 文档和契约不适用于本版本。
