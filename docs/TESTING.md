# 首版验收

## 先分层定位

| 阶段 | 通过标准 | 失败时先看什么 |
| --- | --- | --- |
| iPhone 本机 | 授权后能显示已有健康记录与正确日期 | Health App 是否有记录；数据是否已同步；读取权限 |
| 摘要服务 | `/healthz` 返回成功，真实数据同步后可读取 | Mac IP、端口、防火墙、UPLOAD/READ 令牌是否用反 |
| 浏览器插件 | 使用 READ 令牌显示与手机相同的摘要 | CORS、URL、缓存标记、服务 404/401/409 |
| G2 插件 | 实际 SDK 创建画面成功，手势和退出正确 | Even App ≥2.2.10、眼镜连接、网络白名单 |
| Beta 锁屏 | 锁屏后可启动/操作，旧数据时间仍可辨认 | 正式 Beta 安装、系统调度、网络重连 |

## 真实设备需要你验证的项目

- [ ] iPhone 授权弹窗只请求读取，取消或部分授权后不会显示虚假的 0。
- [ ] 昨晚睡眠跨午夜仍归到正确一晚；卧床与阶段不会重复累计。
- [ ] 今日步数、活动/锻炼/站立和目标与系统口径一致；不将缺失目标硬编码。
- [ ] 最近运动显示其真实日期；最近心率显示测量时间。
- [ ] 未配置服务也能本机读取；未开启同步不上传。
- [ ] 演示有明显标识；退出演示恢复真实/空状态；演示数据无法上传。
- [ ] 手动同步后浏览器和眼镜读取的是同一份摘要。
- [ ] 断网后保留缓存但标记旧数据；恢复后重新刷新。
- [ ] Beta 安装后，锁屏 5 分钟、切换手机 App、再次锁屏仍可操作；不要只用 QR 测试。
- [ ] 根页面双击使用系统退出确认，退出后能够启动其他眼镜应用。

## 自动化检查覆盖

后端重点检查认证作用域、快照验证、持久化、过期上传、删除、CORS、体积限制和错误消息。插件检查数据解析、缺失值、日期/过期状态和页面输出。原生测试检查睡眠区间合并、数据编码、开发/生产 URL 约束及演示上传隔离。

准确的执行结果以对应提交的 GitHub Actions 和 `docs/VALIDATION.md` 为准。没有实际执行的设备测试不得标为通过。

## 反馈

优先从 iPhone App 导出脱敏诊断，附上 App 版本、iOS/watchOS/Even App 版本、发生步骤和页面提示。诊断设计为不包含令牌和原始健康记录；提交截图前也请遮挡令牌。不要把 `.env`、数据库或完整健康导出上传到公开 issue。
